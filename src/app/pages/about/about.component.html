Over deze applicatie

Deze applicatie is gemaakt in het kader van het vak 'Clientside web frameworks' van Avans Hogeschool Breda.

Wat is Musea?

Mijn project is een website waarop gebruikers tentoonstellingen kunnen vinden van museums. Hier kunnen zij informatie over museums zoeken en welke tentoonstellingen deze museums hebben. Bij de tentoonstellingen kunnen gebruikers entreetickets kopen om toegang te krijgen tot de tentoonstelling bij de bijbehorende museum. Verder zullen gebruikers een lijst van vrienden kunnen aanmaken. Als laatste zullen zij ook gebruikers tentoonst aangeraden worden op hun aankopen of de aankopen van vrienden.

Entiteiten

Het datamodel bestaat uit gebruikers, vriendschapverzoeken, museums, tentoonstellingen en tickets. De datavelden kunt u onderin inzien. Een gebruiker bestaat op zichzelf en bestaat uit een aantal velden die gebruikelijk zijn bij een gebruiker van een website. Buiten de de kerndata van een gebruiker zal hij ook een lijst van vrienden (gebruikers) hebben, voordat een vriend kan toegevoegd kan worden moet hiervoor een vriendschapverzoek gestuurd worden die als een lijst ook in de gebruiker staat. Een museum is een entiteit die op zichzelf bestaat. Deze bestaat uit een aantal velden die beschrijven wat het museum is, hoe het bereikbaar is en de website hiervan. Een museum zal verder een lijst van de entiteit tentoonstelling bevatten. Deze bestaat uit een naam, beschrijving en thema bestaan. Daarnaast zal een tentoonstelling informatie bevatten over wanneer deze bezoekbaar is, wat de entree prijs is voor een ticket en de tijden voor elke dag. Als laatste is er nog de entiteit ticket. Deze kan alleen bestaan als er een tentoonstelling en gebruiker bestaat waar deze aan gekoppelt is. Een ticket bevat referenties naar de tentoonstelling en de gebruiker. Daarnaast bevat een ticket de datum van aankoop en status of de ticket nog geldig is, gedeactiveerd of geannuleerd.

Museum

  • id: string (Mongo Id)
  • name: string
  • description: string
  • city: string
  • street: string
  • postalCode: string
  • conctactPhone: string
  • website: string
  • imgUrl: string

Exhibition (Tentoonstelling)

  • id: string (Mongo Id)
  • naam: string
  • description: string
  • theme: string
  • price: number
  • startDate: date
  • endDate: date
  • startTime: date
  • endTime: date
  • imgUrl: string
  • Museum: Museum reference

Ticket

  • id: string (Mongo Id)
  • priceAtPurchase: number
  • dateOfPurchase: date
  • status: Enum (code) -> string (db)
  • exhibition: Exhibition reference
  • user: User reference

User (Gebruiker)

  • id: string (Mongo Id)
  • firstName: string
  • lastName: string
  • email: string
  • password: string -> hash (db)
  • gender: Gender (code) -> string (db)
  • BirthDate: date
  • Role: Role (code) -> string (db)
  • friends: User[] references
  • friendRequests: FriendRequests[] references
